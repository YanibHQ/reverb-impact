# Architecture decision records

ADRs record changes to Reverb's scope, identity, public schemas, evidence semantics, permissions,
compatibility, licensing, and irreversible infrastructure choices.

Accepted ADRs are immutable. A new ADR supersedes an old decision and links it explicitly.
