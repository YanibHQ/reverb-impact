# Reverb brand assets

## Primary logo

![Reverb logo](reverb-logo.png)

`reverb-logo.png` is the primary project mark. Its implied **R** joins one source node to two
downstream nodes through controlled echo arcs, representing traceable cross-repository impact rather
than an unbounded broadcast.

Use the transparent PNG on light or dark neutral backgrounds with clear padding. Do not recolor,
stretch, rotate, add effects, or place it inside another product's mark.

## Provenance

The original mark was generated for Reverb on 2026-08-29 with OpenAI's built-in image-generation
tool using the `logo-brand` workflow. The prompt requested a minimal, vector-friendly, original
midnight-navy and cyan-teal mark with no text, trademarks, gradients, mockup, 3D treatment, or
watermark. The source asset is 1254 × 1254 RGBA with a transparent background.
