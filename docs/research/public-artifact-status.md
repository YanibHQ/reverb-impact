# Public/Research Artifact Status

**Status:** reproducible mechanics artifacts are present; no archival DOI or production/customer
dataset is claimed.

The repository contains public synthetic fixtures, adapter admission reports, the Phase 003 reduced
baselines and raw JSON result, deterministic evaluation/policy code, label handbook, generated
schemas, package checksums, SBOM, and frozen package/tool versions. Mutation and fixture cases test
mechanics and capability only; they are excluded from real-world precision.

Private source, repository/service identity, snippets, raw graphs, human identifiers, reversible
pseudonyms, feedback, and provider payloads are not public artifacts. No independently labeled
customer corpus has been authorized for release, and no production shadow/advisory observation has
occurred. Consequently the repository reports no empirical product precision, recall, action-rate,
or production latency claim.

Before archival release, maintainers must add an approved public corpus/manifest or executable
replica, secret/personal-data scan, exact environment/container digest, analysis commands, raw
predictions/labels permitted for release, baseline licenses, limitations/data statement, and DOI.
Until then, DOI/archive and representative real-world calibration tasks remain unchecked.
