# @yanib/reverb-adapter-events

Deterministic, network-free event and queue contract analysis for Reverb.

The adapter recognizes bounded event manifests and supported literal source bindings for Kafka,
AWS SQS/SNS, and Google Cloud Pub/Sub. It emits versioned destination and payload-schema evidence;
dynamic destinations and unresolved broker namespaces remain explicit coverage limitations.

The package is available beginning with Reverb 0.5.0. Import only its documented root entry point,
pin an exact package version, and keep its version aligned with the rest of the Reverb package set.
